# 汽车音响调音软件

浏览器 / 手机端车用音响调音工具箱（支持 PWA）：信号发生器、RTA 频谱、相位、极性、延时对齐、电平匹配、分频辅助、通道标签与测量导出。

## 电脑打开

麦克风需要 **localhost** 或 **HTTPS**（`file://` 通常无法用麦）。

```bash
cd car-audio-tuner
python3 -m http.server 8080
```

浏览器访问：<http://localhost:8080>

## 手机打开

1. 将本目录部署到支持 **HTTPS** 的静态托管（或电脑与手机同一局域网时，用电脑 IP + 端口；**iOS Safari 测麦克风必须 HTTPS**）。
2. 手机浏览器打开网址。
3. 先点 **「点击解锁音频」**，再点 **「授权麦克风」**（iOS 必须在用户点击后才能启动音频）。
4. Safari / Chrome：分享 → **添加到主屏幕**，可全屏类 App 使用（已提供 `manifest` + Service Worker 离线壳）。
5. 调音时建议手机接车机 AUX/蓝牙播放测试音，音量从低到高；主电平默认约 12%。

### 连蓝牙没声音？

声音从手机喇叭出来：蓝牙勾选「媒体音频」，iPhone 控制中心输出选车机，停止测量后点「⟳ 重置音频输出」（开麦会让系统切到通话路由，App 测完自动关麦并重建音频）。点顶部「🔊 试音」检查音频状态（含麦克风开/关）；关闭静音开关、调高媒体音量；车机音源选「蓝牙音频」；麦克风只在测量时打开（蓝牙下开麦会切到通话模式）；仍不行用 AUX/USB。详见「使用说明 › 没声音？」。

### iOS 注意

- 明文 HTTP 下麦克风 API 不可用，请用 HTTPS。
- 侧边静音开关可能令部分机型无声，请关闭静音并提高媒体音量。
- 切到后台后 Web Audio 可能被挂起，回到前台需再次解锁。
- 手机内置麦未校准，读数仅供相对参考。

## 功能一览

| 模块 | 说明 |
|------|------|
| 12 通道 | CH1–CH12 常见 DSP 布局，名称/声道/单元类型可编辑（本机保存）；点按选择、长按独奏、静音 |
| 通道方案 | 汇总 12 通道延时补偿、增益修正、极性、分频，导出 CSV/JSON 照抄到 DSP |
| 信号发生器 | 正弦、对数扫频、粉红/白噪声、猝发、脉冲；L/R/立体声路由 |
| RTA 频谱 | FFT / 1/3 倍频程；峰值保持；目标曲线参考 |
| 相位测试 | 同相/反相试听 + 麦克风相位差估计 |
| 极性检测 | 正向脉冲 + 麦克风首波正负 |
| 延时对齐 | Chirp/脉冲互相关 → ms / cm；多通道表 |
| 电平匹配 | 相对 dBFS（未校准声压） |
| 分频辅助 | Butterworth 12/24 dB HPF/LPF/BPF |
| 录音分析 | 上传/录制音频，自动分析电平、削波、频谱、问题频点、立体声、EQ 建议；导出 JSON/TXT/CSV |
| 测量记录 | 导出 JSON/CSV，导入 JSON |
| PWA | 可安装到主屏幕，静态资源离线缓存 |

## 12 通道

默认布局：CH1 前左高音 · CH2 前左中音 · CH3 前左低音 · CH4 前右高音 · CH5 前右中音 · CH6 前右低音 · CH7 中置 · CH8 后左 · CH9 后右 · CH10 超低音左 · CH11 超低音右 · CH12 备用/环绕。

默认分频（24 dB/oct）：高音 HPF 3.5 kHz；中音 300 Hz–3.5 kHz；低音 40–300 Hz；中置 HPF 250 Hz；后场 HPF 80 Hz；超低音 LPF 80 Hz。

浏览器只输出立体声：测某通道时请在主机 / DSP 上只开对应物理通道，本工具按声道侧送左/右信号，并逐通道记录延时、电平、极性、分频，在「通道方案」汇总导出。

## 自动调音方案

录音分析完成后自动生成，也可在「通道方案」页点「生成调音方案」，汇总所有已测数据（按通道的录音分析、延时、电平、极性、分频）。按调音顺序输出：

1. 增益/电平：每通道增益修正（以最安静通道为基准，只衰减）
2. 极性：需反相的通道；分频点出现凹陷时建议试反相
3. 分频：在单元默认值基础上按分析调整（如 2–5 kHz 刺耳 → 高音 HPF 上移；低音过重 → 门板低音 HPF 对齐超低音 LPF、超低音 LPF 下调；中/低音之间有空档 → 补齐）
4. 延时：以最远通道为 0
5. EQ：每通道最多 8 段，先衰减；提升 ≤ +3 dB、衰减 ≥ −6 dB；窄而深的谷不硬补；只有整车录音时给整车 EQ
6. 复测与验收标准

缺数据的步骤会写明「先做 xx 测试」，并给出标明「默认值」的起始设置。一键「应用到通道方案」写入 12 通道表（含 EQ 列），支持复制、导出 TXT/CSV/JSON。仅供参考（麦克风未校准）。

## 录音分析

在「录音分析」页上传车内录音（WAV/MP3/M4A/OGG/WebM；iOS 可从「文件」或语音备忘录分享选择），或直接录制 N 秒。所有计算在浏览器本地完成：

- 时长、采样率、峰值/RMS dBFS、峰均比、削波计数，波形总览
- Welch 平均频谱 + 1/3 倍频程，叠加目标曲线并标出 ±4 dB 偏差
- 共振尖峰、低/中/高平衡、低频 -6 dB 点、2–5 kHz 刺耳、5–9 kHz 齿音
- 双声道：左右电平差、相关度（负值提示极性问题）、L/R 时间差（ms/cm）
- 最多 8 段参数 EQ 建议（±6 dB）与中文调音建议

超过 5 分钟的文件只分析前 5 分钟。结果基于未校准麦克风，仅供参考。

## 安全

- 主输出默认约 **12%**，请先低音量确认再升高。
- 测试音可能损坏扬声器与听力，务必渐进调节。

## 局限

- 麦克风未校准；车内反射、蓝牙延时影响精度。
- 浏览器多为立体声输出，多扬声器需在主机/DSP 切换。

## 外录模式（没有 AUX / USB 线）

- **方案 A：U 盘播放**：在「外录模式」下载测试音轨（WAV 44.1 kHz/16-bit，可一键打包 ZIP），复制到 U 盘（FAT32，放在根目录或 CAR_TUNE 文件夹），用车机播放 `01_AUTO_TEST.wav`，同时用手机点「开始外录」。
- **方案 B：两部手机**：手机 A 通过蓝牙播放（不开麦克风），手机 B 录音分析。
- 自动测试轨约 34 秒：3 声同步咔嗒 → 左/右/双声道粉红噪声 → 左右 Chirp（测时间差）→ 正极性脉冲（测极性）。录音分析（实时录音和上传文件都支持）会自动识别同步咔嗒，测出左右电平差、到达时间差、极性和频响，并写入调音方案。
- 需要 MP3 时，请在电脑上转换：`ffmpeg -i 01_AUTO_TEST.wav -b:a 320k 01_AUTO_TEST.mp3`。
- **方案 C：电脑放音 + 手机录音**：电脑通过蓝牙连接车机，在网页「外录模式」直接点「▶ 播放」测试音轨，页面全屏大字提示当前步骤。播放时不申请麦克风，蓝牙保持媒体（A2DP）模式；电脑端不要授权麦克风。手机不连蓝牙，点「外录」按钮录音，自动识别是哪条测试轨并对齐分析。
- 测试音轨还包括 `09_PHASE_TEST`（同相 / 右反相 对比 ×4：全频、40–200 Hz、80 Hz 区、3.5 kHz 区；反相段更响即判定相位相反）和 `10_POLARITY_EXT`（DSP 只开一个单元，逐个测极性），结果写入调音方案第 2 步。
